# Windows実機での確認項目

この表は実機受け入れテストの手順です。チェック欄が空の項目は未確認です。リポジトリの公開、パッケージの生成、自動テストの結果だけで実機検証済みとはなりません。実際のOutlookプロファイル・Teams画面・ヘッドセット・LLM接続を使って確認してください。

## Windows同梱版の起動

- [ ] Windows 11 x64で `giji-automemo-windows-x64.zip` をすべて展開する。
- [ ] Python・Node.js・Gitを別途インストールしていない環境で `GijiAutoMemo.exe` を起動できる。
- [ ] コンソールとブラウザーが開き、未設定状態が表示される。
- [ ] 標準の `small` と話者分離モデルが、追加ダウンロードなしで準備済みと表示される。
- [ ] EXEのそばにある `_internal` と `models` を含め、必要なファイルが配布物にそろっている。
- [ ] 組織の実行制限がある場合、保護機能を無効化せず許可された手順で利用できるか確認する。
- [ ] デモデータは「デモ」と明示され、削除できる。
- [ ] ブラウザーのタブを閉じてからEXEを再起動すると、既存のホームを開き直せる。
- [ ] コンソールを開いたまま利用し、`Ctrl+C` で終了できる。

## Outlookデスクトップ連携

- [ ] Outlook（クラシック）を同じWindowsユーザーで起動し、既存プロファイルの予定を確認できる。
- [ ] Entra登録・クライアントID・テナントID・Microsoft用APIキーを入力せず、予定を同期できる。
- [ ] 今日のTeams予定と繰り返し予定が、Windowsのローカル時刻で表示される。
- [ ] 日をまたぐ会議、繰り返しの例外、同日に複数回ある会議が適切に表示される。
- [ ] Outlookで時刻変更・取消した予定が、標準60秒の次回同期で反映される。
- [ ] Outlookの既定予定表と別の予定表を区別し、対象外の予定を取得済みと誤認しない。
- [ ] 「新しいOutlook」だけの環境では対応外と分かる案内が出る。
- [ ] Outlookのプロファイル選択・サインイン待ち・読み取り拒否で、アプリ全体が固まらず同期状態を確認できる。
- [ ] Object Model Guardの確認が表示された場合、保護設定を変更せず組織の手順で対応できる。
- [ ] 予定を取得できなくても手動録音の設定・操作ができる。

## 録音

- [ ] 同意済みのテスト会議でマイクと相手側の両方の音量メーターが動く。
- [ ] 手動で開始・停止し、マイク音声と相手側音声を再生できる。
- [ ] 物理マイクミュート、Teams上のミュート、アプリの録音停止の違いを確認する。
- [ ] USB/Bluetoothヘッドセットでも、Teamsと同じデバイスを録音できる。
- [ ] 録音中にデバイスを切断するとエラーが表示され、保存済みの音声が残る。
- [ ] 他アプリの通知音が、同じ再生デバイスを使うと録音へ入ることを把握する。

## 自動化と予定変更

- [ ] 自動録音をOFFにした状態では、Teamsへ参加しても録音が始まらない。
- [ ] 自動録音をONにし、Teamsデスクトップで会議へ参加すると録音が始まる。
- [ ] 予定終了時刻を超えても会議中なら録音が続く。
- [ ] 予定より早く退出すると、標準12秒の猶予後に生成が始まる。
- [ ] Teamsウィンドウの最小化・画面切替で不当に停止しない。
- [ ] Teams検知が「不明」の場合は録音を継続し、手動で停止できる。
- [ ] 手動停止後、同じ会議中に即座に録音を再開しない。
- [ ] 同時刻に予定が複数あるとき、会議を勝手に断定しない。
- [ ] アプリの参加操作で選んだ会議と、録音の件名が対応する。

## 生成・復旧

- [ ] 同梱モデルで、自分と相手が交互に話した録音から日本語文字起こしが生成される。
- [ ] 相手が複数人の録音に話者ラベルが付き、実名へ手動編集できる。
- [ ] 外部送信を無効にした状態でLLMへ送らず、文字起こしが保存される。
- [ ] 許可したLLM APIで議事録が生成され、ホームから閲覧・Markdown出力できる。
- [ ] 期限・担当者・決定事項を実際の音声と比較する。
- [ ] APIキー不正やネット切断時、エラーが表示されて途中の文字起こしが残る。
- [ ] 設定を直した後、再処理できる。再処理によるLLM料金の可能性を理解している。
- [ ] 録音中に通常終了した後、再起動すると中断状態と保存済み音声が表示される。
- [ ] アクティブな録音・処理は削除できず、完了した録音は削除できる。
- [ ] 追加モデルを選んだ場合のみ取得が必要になり、利用データ側に保存される。
- [ ] アプリの展開先とは別の利用データ保存先から、バックアップ・復旧できる。

## 任意のGraph接続・開発用ソース版

以下は、組織で既存のGraph接続を使う場合、またはソースから開発する場合だけ確認します。Windows同梱版の通常利用には不要です。

- [ ] 詳細設定でGraphへ切り替えた場合に限り、既存クライアントID・テナントIDとデバイスコード認証を使用する。
- [ ] Outlookデスクトップへ戻した場合、Graphの認証状態にかかわらず予定同期を試せる。
- [ ] ソース版はPython 3.11 x64と必要な開発環境を用意し、`scripts/setup.ps1` と `scripts/start.ps1` で起動できる。
- [ ] ソース版のモデル未取得状態と、モデル同梱版の準備済み状態を区別できる。

認証・録音の実データやAPIキーを公開リポジトリへ追加せず、実施した環境と結果だけを記録してください。
