# 検証結果

v0.3のTeamsデスクトップ連携はプレビューです。実装済みと実機検証済みを区別して記載しています。

## v0.3のTeams予定連携に関する範囲

実際のTeamsアカウントを使うWindows PCがこの開発環境にはありません。Teamsの予定取得、当日の全予定を網羅できること、Teams更新後の表示との互換性は実機検証していません。テスト用に作成したDOM・アクセシビリティ情報・CDP応答を使う検証は、実際のTeams画面から採取したデータでの確認とは区別します。

MicrosoftのUI Automation、WebView2/CDP仕様とTeamsカレンダーのアクセシビリティ操作は一次資料で確認しています。ただし、その資料がこのアプリの予定取得を保証するものではありません。[Teams連携の方式と資料](teams-desktop.md)

## v0.3：この開発環境で確認したこと

- Pythonの自動テスト361件成功。標準UIAの読取専用処理、所有プロセスの確認、日時の解析、
  読取時間の上限、部分取得の保持、取得元の切替、予定選択、既存の録音・生成処理を確認。
- 上記には、実Chromiumで合成ページを表示して行う8件のCDPテストを含みます。
  別プロセスのiframe、同一プロセスのiframe、非表示フレームの除外、重複候補、
  ミニカレンダーの日付を誤用しないことなどを確認。実Teamsの画面を使う検証ではありません。
- 任意CDPの一時設定、既存設定の保護、所有者・接続先検証、復元用プロセスの起動確認、
  期限切れ・接続切れ・再準備を注入可能なテスト用バックエンドで確認。
- Ruff静的検査、TypeScriptチェック、Vite本番ビルドが成功。
- ChromiumのAPIフィクスチャで標準UIAの同期がCDP準備を呼ばないこと、CDPの明示切替、
  録音中の解除が録音停止を呼ばないこと、予定選択と手動録音、390px幅の表示を確認。
  JavaScript例外なし。
- 現在の実バックエンドをLinuxで起動し、明示したデモの一覧・議事録・文字起こし、
  話者名編集、Markdown書き出し、設定保存、デモ削除をChromiumで確認。
  ホーム・設定・議事録の画像もこの実行から更新。WindowsのTeams連携の証跡ではありません。

Windows同梱版のv0.3検証結果は、完了後に追記します。この文書のv0.2の結果を
v0.3のWindows動作確認に読み替えないでください。

  無音マイクのトラックで誤った発話を生成しないことも確認。

  `av>=14,<17` に依存範囲を制限。
- 完成済みユーザーモデルと同梱モデルの優先順位、不完全なモデルの検出、
  同梱モデルをコピー・ダウンロードせずに使う経路を検証。
  同梱配置を指定した実モデル推論でも、利用者用モデルフォルダーが作成されないことを確認。

自動テストではMicrosoft・LLMのHTTP応答とWindowsのデバイスをモックしています。
実モデルの推論検証はLinux上の短いサンプルで、長時間・日本語・複数話者の精度を
保証する測定ではありません。

## 利用するWindows PCで必要な確認

- Outlookを必要とせずTeamsに接続し、今日の予定を読み取れること。日本語・英語、
  Teams内のカレンダーiframe、画面切替・仮想スクロール、予定変更・取消の確認が必要です。
- 標準UI Automationで接続準備・Teams再起動・レジストリ変更なしに読み取れること。
  WindowsとTeamsのタイムゾーン、最小化時の読取可否、補助プロセスの終了も確認が必要です。
- 任意のCDP方式で、一時設定の復元、準備の期限切れ、アプリ再起動後の再準備、
  解除後のTeams通常再起動でデバッグ接続が閉じること。会社の管理ポリシー下での動作も未確認です。
- Windows 11、利用中のTeams版、ヘッドセットでのUIA検知とWASAPI録音。
- Teamsを最小化した場合、会議の延長・短縮、退出・再参加の実動作。
- 使用するLLM APIキー・モデルでの議事録生成。
- 使用する会社PCで、未署名の配布EXEを起動できること。
- 任意のGraph連携を選ぶ場合だけ、Microsoft 365テナントの認証・権限・予定取得。
- 任意のOutlook連携を選ぶ場合だけ、クラシックOutlookのプロファイル・予定・定期開催回・
  変更・取消とObject Model Guardの確認。

実アカウント・Windows端末・ヘッドセット・実APIキーはこの開発環境にないため、
上記の実機検証は行っていません。手順は[実機確認項目](acceptance.md)にあります。
GitHub ActionsのWindowsジョブもハードウェアやTeamsの実会議を検証するものではありません。
